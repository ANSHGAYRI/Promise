PROMISE APP

Files:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

PHONE:
This is a Progressive Web App (PWA). After the files are hosted on HTTPS:
Android Chrome -> open the website -> menu -> Add to Home screen / Install app.

WEB:
The same index.html is the web app. Upload all files to any HTTPS static host.

IMPORTANT:
A public Google/web address requires hosting. This package itself is not automatically published to Google Play or the public internet.
